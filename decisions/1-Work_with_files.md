task1 - Работа в консольке
1. Переместиться между директориями: cd (например, cd /путь, cd .., cd ~).
2. Вывести список файлов в директории: ls (подробно: ls -l).
3. Вывести список ВСЕХ файлов: ls -a.
4. Создать папку с подпапками: mkdir -p папка/подпапка/вложенная.
5. Внутри папки создать файл и записать текст: echo "Текст" > путь/файл.txt (или >> для добавления).
6. Переместить файл: mv исходный/файл целевая/директория/.
7. Скопировать файл: cp исходный/файл целевая/директория/ (для папок: cp -r).
8. Переименовать файл: mv старое_имя новое_имя.
9. Сравнить содержимое файлов: diff файл1 файл2.
10. Отсортировать содержимое файла: по возрастанию - sort файл, по убыванию - sort -r файл.
11. Удалить все папки и файлы (опасно!): rm -rf имя_директории (удаляет рекурсивно и без подтверждения).

task2 - Перенаправляем
1. '>' - перезапись файла выводом команды. '>>' - добавление вывода в конец файла.
2. Перенаправление - управление потоками данных: stdin (ввод, дескриптор 0), stdout (обычный вывод, дескриптор 1), stderr (вывод ошибок, дескриптор 2).
3. Вывести содержимое файла: cat файл или less файл.
4. Создать файл с содержимым: echo "текст" > файл ИЛИ cat > файл, ввести текст, Ctrl+D.
5. Перенаправления:
kinit user 2>&1 - объединить stderr с stdout (ошибки идут в общий поток).
ping host > output.log 2>&1 - весь вывод (stdout+stderr) в файл.
tracert host 2> /dev/null - stderr в "пустоту", stdout на экран.
6. Отличие stdout/stderr: stdout - обычный результат работы, stderr - сообщения об ошибках (идут отдельно, можно фильтровать).
7. stdin - стандартный ввод (с клавиатуры или из файла через <).
8. Отправить весь вывод в пустоту: команда > /dev/null 2>&1 ИЛИ команда &> /dev/null.
